# Changelog

## [1.0.0] — 2026-04-01

### Added
- Sports performance metrics: xG logistic model, VAEP action-value framework, player rating systems (PER, plus-minus)
- Tactical and tracking data resources: StatsBomb open data, Wyscout, Opta schema references
- Multi-sport analytical frameworks: Elo ratings, Monte Carlo simulation, Dixon-Coles match prediction
- Betting and predictive models: Kelly Criterion, Poisson match model, closing line value (CLV) methodology
- Value betting and bankroll management: ruin probability model, fractional Kelly, EV calculation
- Historical data sources: Sports Reference Network, Hudl StatsBomb, Opta/Stats Perform API guide
- Nutrition and metabolism section: TDEE models, Mifflin-St Jeor and Katch-McArdle equations, macro split reference
- Diet protocol models: Keto, Paleo, Vegan, Mediterranean macro targets
- Supplementation science: creatine loading phases, caffeine half-life curve, Examine.com reference
- Cycling science: FTP-based power zones (Coggan 7-zone), VAM estimator, gear ratio tables
- Health and vitality: hydration calculators, sleep cycle optimisation, paediatric dose reference
- Pet health section: RER/DER formulas for dogs and cats by life stage
- Open datasets registry: StatsBomb open data, FBref, Kaggle sports datasets, UCI ML repository
- Python libraries: pandas, scikit-learn, mplsoccer, socceraction, soccerdata toolkit references
- R packages: worldfootballR, nflscrapR, sportyR visualisation tools
- Academic conferences and journals: MIT Sloan Analytics, IJSPP, Journal of Sports Sciences
- Courses and learning paths: Coursera sports analytics, DataCamp, StatsBomb education resources
